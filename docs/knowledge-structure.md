# 知识组织与证据范围

目录层次为学科、模块、知识点、子知识点，目录节点与可评价范围不同。每个现行可评价范围对应knowledge/items/KP-*.json的一份实体；新增未分类范围可暂缺父模块。目录不保存第二套掌握与日期。

原K-IMPORT和D等161个ID保留为legacy_source资料。legacy-map是原始资料到标准范围的映射，不是复习队列。原资料内容和迁移前证据保留为来源快照，现行更新只在对应KP实体；汇总不得将两处证据重复计数。

同一范围可被多个资料和目标引用，只安排一次复习。容器、资源、课程收藏不直接作为考试知识。宽泛能力范围仍可继续拆分；拆分时只转移明确对应证据，父结果不能传给未测子项。

knowledge/catalog/nodes.json是目录与证据引用；statistics.json和queue由脚本派生。catalogue.py --validate检查层级、引用、目标大纲、派生队列一致性，不等于内容已核验或大纲覆盖完整。

目标分类按版本化大纲章节标注依据；目标完成不删除共享知识。生命周期详见[知识生命周期](knowledge-lifecycle.md)。
