# 分层知识与证据映射 taxonomy-v1

更新2026-10-11。knowledge/catalog/README.md是面向阅读的入口；JSON目录为可校验的映射。所有161个原始ID、内容、来源、既有attempt、queue、backlog和session继续保留。

## 结构与统计

节点层次subject/module/concept/subconcept；原始条目角色atomic、bundle、capability、collection、container、resource。某个能力可以继续细分，不强求统一拆成词条级。英语语法总览是目录；英语习惯、MOOC是参考资源；大词汇列表保留collection及尚未逐词拆分的范围。253个可评价范围并非253个均已核验的原子事实，也不是完整考试大纲。

同一个标准节点可以关联多个原始条目；33个共享范围已统一，例如比较级、go词形、旋转体、二分边界。部分重叠只合并公共范围，其余范围保留。目录保留主父节点，跨模块关联通过legacy-map表达，不重复复制概念。词义推断与篇章含义推断、连接词选择与阅读理解保持不同范围，相关不等于重复。

来源数、标准范围数、作答数、活动状态、掌握证据分别统计。`python scripts/catalogue.py --validate`检查映射及统计；statistics.json和README为本次快照，后续变更应重新生成。目录验证不等于知识内容验证。覆盖缺口是助手提出的待核对线索，未对照官方完整大纲，不计算覆盖率。

## 证据迁移

question-map记录31道既有题的范围，保持题目ID、文本及状态。evidence-map对应19份独立attempt的53项评价，批次汇总不重复计。D系列的position是评价要点位置，其余通常是小题序号。保留原correct/wrong/unknown/partial，不重新评分；原记录未说明独立性、间隔，保持null。所有长期验证仍为false。不能将一条父模块的stage/正确结果复制给全部子项。

例：K-IMPORT-063实际两题仅映射“基本极限计算”，等价无穷小与洛必达没有因此获得证据；K-IMPORT-015分别映射er、more及不规则比较级，最高级不继承评价。原始日程继续负责到期，不为新增节点创建历史复习日期。

## 调度衔接

learning.py CLI通过catalogue.load_context读取标准范围。已有复习条目的范围来自真实评价映射；尚未诊断的条目不再以其他条目已测试过的公共范围作为首次诊断。现有未答题按question-map续接，不因整理被换题。

开放题、当天已派题涉及的标准范围阻止其他ID重复新派；同批新候选只保留未被已选动作覆盖的范围。已存在的开放题不自动撤销，遇到历史重叠应继续原题并记录覆盖。旧review.select/questions.plan仅兼容，不具备完整标准范围去重，日常使用learning.py。

原始条目仍是持久调度单位，canonical_ids是该动作实际可考范围；一个动作可包含多个相关小题，但每个小题必须记录具体标准ID。复习间隔暂未迁移为每个子知识独立日期，避免凭一次旧测验复制出多条复习债务。目录/资源不自动派题；范围为空或尚未准备，返回需补范围的阻塞项。集合型资料须逐项核验准备后才能纳入调度，不直接测试整个列表。

新出题时：确定标准范围→核验题目与标准答案→调用issue(..., canonical_ids=[...])→保存backlog/session/question-map/current。旧题可先load_context加载已有canonical_ids，再调用issue，检查别名间的开放范围冲突。直接裸调用旧接口无目录上下文时不能保证跨ID去重。

回答评价后：原attempt及调度、question状态照常更新，同时在evidence-map追加实际小题范围与结果，关联nodes的证据引用，更新统计。多维度独立/延迟证据只按真实记录填写；错误修订通过revision保留历史。此跨文件保存仍由对话中的助手原子提交，没有后台自动统计或写入。

## 归档与完整性

73个C/Shell条目和4道暂停题保持原状。活动/归档属于原始条目调度状态，不改变认知评价。单个标准范围的availability是本次快照；恢复按queue/item实时状态执行。新目录不会自行恢复归档。

当前英语关联现有四级目标的新增映射是助手暂定中等贡献，未宣称考试权重。高数/计算机的目标激活依照原目标状态；缺少目标确认时不擅自新增目标。
