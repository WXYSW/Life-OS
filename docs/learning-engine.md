# 学习决策与证据

正常入口scripts/learning.py委托lifecycle.py，读取record_type=knowledge的KP实体和目标。默认mode=review；显式mode=diagnose才提取未测知识。旧plan_actions及questions.py是内存纯函数兼容接口，不承担当前生命周期或跨聊天持久化。

## 选择流程

先排除归档和当批已安排ID；复习只取tested且有有效活跃目标的范围；诊断只取untested，不要求事先完成目标匹配。内容未核验列入blocked，核验后才能评分。已测且没有可用日期的范围安排独立验证，不能编造历史到期日。

在活跃目标间按重要性、明确近截止日期和已知差距分配预计时间；未知重要性采用中性份额。同目标内先看直接要求/必要基础，再看有依据的目标内重要性、前置作用、薄弱证据、到期日和稳定ID。未知难度与考频不生成假分数。未证明前置应用能力会阻塞新诊断；部分相关目标关系不确定时保留待确认。

复习初始批量5，诊断2，用户可改变数量；没有每日上限。minutes限制当批预计时间；没有个人估计时默认每范围10分钟，低精力5分钟，均为临时估计。返回候选不是出题或已完成。

## 独立范围评价

每事件只关联一个KP知识点，使用稳定事件ID，重复提交幂等，ID冲突或倒序评价拒绝。其他知识的schedule不受影响。答案原文、题干、选项均不入库；basis和weakness只用简短评价理由。未知独立性保留null，正确但独立性未知不推进阶梯；提示正确按hinted处理。

record_evidence遇到KP实体委托lifecycle.evaluate；脚本采用原review.grade进行调度。正确、错误、提示由评价依据决定；unknown/partial保留但不擅自转成wrong。practice/relearn及skip不推进阶梯。错误即使标注延迟/迁移也不会成为成功证据。同日同知识最多一次调度更新，额外表现只记精简证据。

纠正评分需要基于证据按时间重放，当前脚本会拒绝直接覆盖或倒序写入，助手需准备明确修订。复习板块长期验证统计要求两次实际间隔至少30天的独立正确、可调度表现；历史未知证据不计入。
