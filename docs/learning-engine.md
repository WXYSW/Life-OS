# 学习决策与证据

正常入口scripts/learning.py：默认review正式复习，diagnose主动诊断，reinforce主动目标强化。正常复习和强化由review_engine.py实施四模块决策；lifecycle.py负责知识生命周期、评价、归档、目标重检和派生数据保存。

完整规则见[动态复习系统](review-system.md)。目标掌握要求按关系分别保存，记忆状态共享；只有核验和有效测试均满足的知识进入正式复习。

风险层优先于目标紧迫性；同层再判断收益、目标和知识类别分布。标准轮最多5个知识范围，轻量3、深度8，均不凑数。数量不是题数，minutes限制预计时间；未知时长标为暂定估计，不推测用户可用时间。

每个动作解释选择原因；计划不写永久任务库。当前对话用assigned避免同轮重复，完成评价后再次读取知识重新规划。题目临时生成，未知目标要求保持未知。

评价记录每个范围的精简证据和独立性、维度、质量、错误类型。普通正式评价仍调用原review.grade。强化、即时练习和讲解强制不改变阶梯；当日练习暴露后的成功不能算新的延迟记忆通过。错误的延迟回答不算长期成功；未知独立性不能升级为独立通过。

schedule_changed及memory_effect是引擎生成的简短审计字段，防止同日重复和强化练习污染长期验证统计。memory每次保存重算，计划时按指定日期重新计算风险，过期缓存不影响排序。

lifecycle.py的--write更新知识、目标与派生队列、节点、视图、统计、知识摘要；助手核对后提交GitHub。生活records/与reports/不受知识操作影响。旧plan_actions、review.select和questions.py仅保留兼容，不能替代当前入口。
