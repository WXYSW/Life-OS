# 临时出题与评价

题目只在当前对话存在，不维护题库、未答题清单、session或完整答题流水。开始前确定知识范围和评价要点，回答后讲解；当前对话用临时KP-ID集合防重复，跨聊天按知识重新出题。

未答不算错；跳过不改调度。测试完成与掌握程度独立。新知识由用户主动启动测试，复习只安排已有目标关联的已测范围。精简事件的格式见templates/learning-event.json。

保存依据、独立/提示/查阅情况、结果、维度、质量和薄弱点，不保存完整题干或原答。未知情况保留null，不编造长期掌握。每个知识独立评价，不能将整题平均成绩传给各子知识。

状态转换、目标重检和归档删除见[知识生命周期](knowledge-lifecycle.md)。
