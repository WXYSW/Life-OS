# 日常操作流程

生活板块和知识板块独立运行，可以从同一段描述提取不同数据。

## 生活记录

读取相关records/和当前摘要。区分事件时间、提交时间、来源；补记按事件日期归档。事实、用户感受、估计、解释和助手推断分开，未知用null。计划不当完成，同一事件不重复统计。

提取工作、学习时长、睡眠、情绪、人际、娱乐、消费和环境等相关数据，不能只记录学习。仅追问影响判断的缺失信息；“简单记录”时减负。简短给出一个主要观察或下一步建议，相关不当因果，不作无依据诊断。

生活记录保存在records/YYYY/MM/DD/；日报在reports/daily/YYYY/MM/；周月季年报告分别在对应目录。未完周期标注截至时间。用户“今天结束”后整理日报，补记与更正保留来源版本并标记依赖报告待更新。历史数据不能当作今天状态。

生活板块的学习时长不作为知识掌握证明。删除知识不删除生活记录或报告。

## 知识处理

日常只提取知识并去重，创建稳定KP-ID进入待检测；用户主动要求测试或归档。测试前核验内容及评分依据，临时出题，回答后保存精简证据，再按目标大纲关联。复习默认不夹带待检测知识。

完整流程、归档恢复、目标完成后的重新检查和删除边界见[知识生命周期](knowledge-lifecycle.md)。保存时使用lifecycle.py构建派生队列、视图、节点索引、统计和知识摘要，再同次提交。旧资料ID不参与现行派题。

## 同步

本仓库是公开保存区。已授权知识及精简证据无需逐次确认；用户明确排除优先。其他日常新原话沿用既有公开范围。提交前核对最新分支，冲突重读合并；提交后核对远程再反馈。不自动强推、重写历史或启动后台任务。
