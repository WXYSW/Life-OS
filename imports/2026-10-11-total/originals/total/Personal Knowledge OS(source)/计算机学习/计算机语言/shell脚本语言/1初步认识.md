当你在 shell 中执行命令时，您实际上是在执行一段 shell 可以解释执行的简短代码。如果你要求 shell 执行某个指令，但是该指令并不是 shell 所了解的编程关键字，那么它会去咨询 _环境变量_ `$PATH`，它会列出当 shell 接到某条指令时，进行程序搜索的路径：
	```
	missing:~$ echo $PATH/usr/local/sbin:/usr/local/bin:/usr/sbin:    /usr/bin:/sbin:/bin
	missing:~$ which echo
	/bin/echo
	missing:~$ /bin/echo $PATH/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

echo #PATH
