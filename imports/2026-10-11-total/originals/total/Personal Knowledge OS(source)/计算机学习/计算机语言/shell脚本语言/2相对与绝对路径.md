c目录下有1，missing两个文件夹1文件夹中也有一个叫missing的文件夹，当我要进1文件夹中的missing我应该输入cd /c/1/missing，当我要进c目录下的missing则可以直接输入cd missing前者是绝对路径后者则是相对路径

举例- **绝对路径** = "中国北京市海淀区xx路xx号"（全球唯一）
    
- **相对路径** = "从你现在的位置出发：直走100米右转"（取决于你当前在哪）

输入格式

绝对  cd  missing或cd ./missing

相对  cd /c/missing 

shell 中的路径是一组被分割的目录，在 Linux 和 macOS 上使用 ==`/`== 分割，
而在 Windows 上是 ==`\`==
