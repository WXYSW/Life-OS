return停止函数的执行，并送回一个值
如
	return；
	return 表达式；
一个函数里可以出现多个return语句

细节
	使用函数时最好采用单一出口方便代码后期的调试
	
可以赋值个变量
可以再传递给函数
甚至可以丢弃
如
代码块
	`int max(int a, int b)`
	`{`
		`int ret;`
		`if( a>b )`
		`{`
		`ret = a;`
		`}`
		`else`
		`{`
		`ret = b;`
		`}`
		`return ret;`
	`}`
代码块
	int a,b,c;
	a = 5;
	b = 6;
	c = max(10,12);
	c = max(a,b);
	c = max(c,23);
	c = max(max(c,a),5);
	printf("%d\n",max(a,b));
	max(12,13);

没有返回值的函数
	void 函数名(参数表)
	不能使用带值的return
	可以没有return
	调用的时候不能做返回值的赋值
