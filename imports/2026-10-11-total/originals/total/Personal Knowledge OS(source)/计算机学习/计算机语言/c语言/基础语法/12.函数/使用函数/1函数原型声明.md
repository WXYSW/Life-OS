
函数头,以分号";"结尾，就构成了函数的原型
函数的原型的目的是告诉编译器这个函数长什么样
	名称
	参数（数量及类型）
	返回类型

例子
	#include <stdio.h>
	void sum(int begin, int end);            //声明函数begin和end不写是可以的因为只是参数的名称
	//函数原型声明，告诉编译器函数的名称、参数类型和返回值类型
	int main()
	{
	    sum(1,10);
	    sum(20,30);
	    sum(35,45);
	    return 0;
	}
	void sum(int begin, int end)            //函数定义
	//函数定义，函数体包含了函数的具体实现
	{
	    int i;
	    int sum =0;
	    for ( i=begin; i<=end; i++)
	    {
	        sum += i;
	    }
	    printf("%d到%d的和是%d\n",begin,end,sum);
	}
