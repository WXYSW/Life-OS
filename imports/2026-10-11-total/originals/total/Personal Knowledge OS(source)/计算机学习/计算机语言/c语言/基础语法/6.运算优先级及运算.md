
1	（）				从左到右				括号
2	！+ - ++ --		从右到左（单目的+和-）如a++
3	* / %			从左到右				乘除
4	+-				从左到右				加减
5	< <= > >=		从左到右				比大小
6	== !=			从左到右				等于不等于
7	&&				从左到右				两边都满足
8	||				从左到右				满足一边
9	= += -= *= /= %= 从右到左				a=b把b赋值给a			

| `a++` | 先返回 `a` 的原始值，再对 `a` 加 1 |
| ----- | ----------------------- |
| `++a` | 先对 `a` 加 1，再返回 `a` 的新值  |
int b = a++;  // b = 5，之后 a = 6
int c = ++a;  // a 先变成 7，之后 c = 7

a+=10等于a = a+10
a /=10也就等于a = a/10

&是一个运算符用于将变量转换为变量地址
