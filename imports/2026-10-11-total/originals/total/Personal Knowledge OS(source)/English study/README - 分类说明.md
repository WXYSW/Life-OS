# 英语学习资料｜重新分类版

本压缩包按照以下英语整体知识结构重新整理：

知识系统
├── 词汇
├── 语法
└── 语音

输入
├── 阅读
└── 听力

输出
├── 写作
└── 口语

## 本次整理原则

1. 原有学习笔记尽量保留原文，仅调整所在目录和部分文件名。
2. 名词、动词、形容词/副词、介词、第三人称单数等均归入「知识系统/语法」。
3. 单词、短语、搭配及原来的“阅读词汇”归入「知识系统/词汇」；“阅读词汇”虽然来源于阅读，但其内容本质上是词汇知识，因此仍放在词汇。
4. 原压缩包没有独立的语音、阅读、听力、写作材料，因此这些目录目前保留为空，没有强行归类。
5. “英语十大习惯”同时涉及听力、发音、口语、写作等多个方面，无法合理归入单一输入类别，因此放在「输出/口语」下，并标记为“综合练习”。
6. Obsidian 的 `.obsidian` 配置和原 `.trash` 保留在根目录，不把它们当作英语学习知识分类。

## 说明

这是“内容归类版”，不是对知识内容本身进行重写或纠错。
