- 大多数名词，直接在词尾加 -s
    
- 需要特殊处理的规则变化
    
    - 以 -s, -x, -z, -sh, -ch 结尾的名词在词尾加 -es
        
- 2. 以 辅音字母 + y 结尾的名词变 y 为 i，再加 -es。
        
- 3. 以 -f 或 -fe 结尾的名词多数情况变 f/fe 为 v，再加 -es。发音为 /vz/。
        
    
    - leaf → leaves
        
    - wife → wives
        
    - wolf → wolves
        
    - thief → thieves
        
    - knife → knives
        
- 常见例外（直接加 -s）：
    
    - 4. 以 -o 结尾的名词情况比较复杂，但主要遵循以下规律：
            
        
        - 有生命的/常用词，通常加 -es：
            
        - potato → potatoes
            
        - tomato → tomatoes
            
        - hero → heroes
            
        - echo → echoes
            
    - 无生命的/外来词/缩写词，通常加 -s：
        
        - photo → photos
            
        - piano → pianos
            
        - kilo → kilos
            
        - radio → radios
            
        - zoo → zoos

- 注意：有些词两种方式都可以
